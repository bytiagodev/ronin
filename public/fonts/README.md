The Japanese quotations, scroll kanji, names and glossary terms are set in Yuji Syuku, subset to the characters the site uses (`yuji-syuku-subset.woff2`, built by `scripts/build-brush-font.py` from `@fontsource/yuji-syuku`). Yuji Syuku is licensed under the SIL Open Font License 1.1, and its notice is included here.
